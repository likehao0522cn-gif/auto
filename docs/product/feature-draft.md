# 调音节拍器：功能规格草案

版本：1.1  
状态：已被 `docs/product/functional-spec.md` 取代，保留为设计过程记录。

## 1. 产品定位

面向盲人和低视力用户的 iPhone 听觉优先调音与节拍器应用。

首版同时服务：

- 自己给单音乐器调音的乐手。
- 需要逐键检查钢琴音高的钢琴演奏者。
- 需要基础节拍器功能的音乐学习者。

首版不包含：

- 专业钢琴调律。
- 拍频分析、同度调整、拉伸调律。
- 复音识别、和弦识别。
- 录音分析、账号、云同步。
- Android 版本。

## 2. 已确认的产品决策

### 2.1 平台、语言与数据

- 原生 iOS，首版只做 iPhone。
- 简体中文优先，同时支持英文。
- 所有音频分析在设备端完成。
- 不录音、不上传音频。

### 2.2 信息架构

主导航只保留：

```text
首页
├─ 调音器
│  ├─ 乐器预设
│  ├─ 目标音模式
│  ├─ 参考音
│  └─ 钢琴逐键检查
├─ 节拍器
└─ 设置与帮助
```

钢琴不单独占主入口，作为调音器中的一个预设。

### 2.3 启动与快速开始

- 每次启动回到首页。
- 记住上次使用的乐器、弦位和设置。
- 不自动开启麦克风。
- 不自动播放参考音。
- 不自动开始节拍器。
- 首页提供“快速调音”和“快速节拍”，使用上次的乐器和设置。

### 2.4 音名与音高

- 默认使用字母音名，例如 C4、A4。
- 可在设置中切换固定唱名。
- 默认十二平均律。
- 标准音高 A4 默认 440 Hz，可调范围 392–466 Hz。
- 音高偏差以音分表示。
- 默认准音容差为 ±3 音分，可切换 ±1、±3、±5 音分。

### 2.5 检测模式

**自动识别模式**

- 应用推断最近的目标音。
- 适用于钢琴和半音模式。

**锁定目标音模式**

- 用户先选择弦位或目标音。
- 应用只判断实测音高相对该目标的偏差。
- 弦乐器默认使用此模式。
- 弦乐器允许切换到自动识别模式，但切换后不改变默认值。

### 2.6 乐器预设

首版包含：

- 半音模式。
- 吉他标准调弦。
- 尤克里里标准调弦。
- 小提琴。
- 大提琴。
- 二胡。
- 古筝标准 D 调 21 弦。
- 琵琶标准定弦。
- 钢琴逐键检查。

中国乐器中，古筝和琵琶做专用预设；其他中国乐器可先使用通用半音模式。

### 2.7 调音器主流程

1. 选择乐器。
2. 选择弦位。
3. 进入调音器后自动开始持续监听。
4. 用户拨弦。
5. 应用检测到拨弦事件后自动播报一次结果。
6. 用户继续调弦，再次拨弦后自动播报下一次结果。
7. 需要时可播放参考音或主动查询最近一次结果。

### 2.8 监听与播报

- “持续监听”指调音器页面打开期间麦克风保持工作，不是持续朗读。
- 默认反馈是事件播报，不连续朗读。
- 检测到起音后采集约 1 秒，取中间稳定片段作为本次结果。
- 每次拨弦产生一次初始结果。
- 同一持续音中，以最近一次已播报结果为基准；变化超过 5 音分并持续约 300 毫秒才再次播报。
- 每次拨弦最多自动更新 3 次；再次拨弦重新计数。
- 自动更新的播报方式有两种，用户可以在设置中选择：
  - 方式一：变化数字 + 触觉，例如“低 8 音分”。
  - 方式二：只用短音型和触觉，不播报数字。
- 默认使用方式一。
- 方向或准音状态变化时，补充完整结果。
- 连续静音约 300 毫秒后允许开始下一次拨弦事件，避免余音中的短暂空隙被误判为新拨弦。
- 结果不变时不重复播报。
- 用户可点击“查询结果”重播最近一次结果，不重新监听。
- 检测不到声音时保持安静，不自动报错；用户查询时播报“还没有检测到稳定音高”。

### 2.8.1 离开页面与中断

- 离开调音器页面时立即停止监听并释放麦克风。
- 返回调音器时自动恢复监听，但清空上一次结果。
- 打开帮助、设置或播放参考音时暂停监听。
- 从帮助或设置返回后自动恢复监听，并保留上一次结果。
- 进入后台时停止调音监听；节拍器按设置继续播放。

### 2.9 调音反馈

- 音高稳定后播报一次完整结果。
- 音分偏差按 1 音分精度播报。
- 结果不稳定时使用“约低 10 音分，请再弹一次”一类措辞。
- 弦位同时播报弦号和音名，例如“六弦，E2”。
- 偏高使用上行两音。
- 偏低使用下行两音。
- 准了使用单声确认音。
- 触觉反馈：偏高两次短震，偏低一次长震，准了两次短震。
- 首版不提供连续播报。

### 2.10 参考音

- 参考音只在用户明确操作时播放。
- 默认使用纯正弦音，可切换钢琴音色。
- 播放参考音时暂停麦克风分析。
- 播放结束后自动恢复聆听，并语音提示“继续聆听”。

### 2.11 声音输出

- 不做单耳模式。
- 所有应用声音从两侧输出。
- 任何应用发声期间都暂停或忽略音高分析。
- 提示音和语音尽量短，避免长时间遮住乐器声。

### 2.12 钢琴逐键检查

- 覆盖 A0–C8 全部 88 键。
- 默认自动识别。
- 弹一个键，报告音名和音分偏差。
- 低音区结果不稳定时，提示重新弹奏或切换到锁定目标音。
- 偏差接近半音边界时，提示可能接近相邻音。
- 只保留最近一次结果，不做检查历史。
- 不判断同一琴键多根弦中具体哪根弦不准。
- 锁定目标音时采用“先选八度，再选音名”。
- 检测到多个音时，不猜测具体音高，播报“检测到多个音，请一次弹一个音”。

### 2.13 节拍器

默认值：

- 120 BPM。
- 4/4。
- 第一拍重音。
- 无预备拍。
- 点击声。
- 默认不语音数拍。

功能：

- BPM 范围 20–300。
- 支持 VoiceOver 调节手势和加减按钮。
- 拍号：1/4、2/4、3/4、4/4、5/4、6/8、7/8、9/8、12/8。
- 重音：默认第一拍重音，可选每拍重音。
- 测速：主页面入口；支持屏幕区域点击和音量键记录拍点。
- 细分拍：无、二连、三连、四连。
- Tap Tempo 测速。
- 预备拍：关闭、1 小节、2 小节。
- 播放和停止有明确语音状态。
- 支持锁屏和后台播放。
- 触觉打拍为可选辅助；后台和锁屏时不承诺触觉持续可用。

### 2.13.1 节拍器页面结构

节拍器采用“主页面 + 3 个设置子页面”的结构：

- 主页面：播放状态、BPM、开始或停止、进入各设置子页面。
- 节拍设置子页面：拍号、重音、细分拍。
- 测速子页面：使用一个占据主要屏幕区域的“测速区域”，连续记录拍点后推算 BPM。
- 预备拍子页面：关闭、1 小节、2 小节。
- 所有子页面都提供返回主页面和帮助入口。

### 2.13.2 测速交互

- 节拍器主页面提供“测速”入口。
- 测速页提供一个占据主要屏幕区域的“测速区域”，不需要精确点中按钮。
- VoiceOver 开启时，测速区域允许直接触摸，单击即可记录拍点；同时保留可激活的替代操作。
- 测速区域无论 VoiceOver 是否开启，都不要求双击。
- 进入测速页后，第一次单击或第一个音量键按下就开始测速，不需要先按“开始”。
- 测速页打开期间，每按一次音量键记录一拍；音量键只记录拍点，不改变系统音量。
- 满 3 拍后播报初步 BPM；之后每多一拍更新一次并逐渐稳定。
- 约 3 秒没有新拍点时自动重置。
- 测速页显示 BPM，并提供“应用到节拍器”按钮；应用后返回节拍器主页面。
- 测速结果不会自动覆盖当前 BPM，必须由用户确认应用。
- 每次记录拍点时播放一个很短的确认音，并提供可关闭的触觉反馈。
- 确认音和触觉只确认拍点已经记录，不改变测速节奏。
### 2.14 节拍器主流程

1. 从首页进入节拍器，默认不播放。
2. 用户设置 BPM、拍号、重音、细分拍和预备拍。
3. 点击“开始”，按设置播放。
4. 离开节拍器页面后继续播放。
5. 首页显示“节拍器正在播放，120 BPM，4/4”，并提供停止按钮。
6. 用户点击“停止”后停止，并语音确认“节拍器已停止”。
7. 节拍器不会因离开页面、锁屏或播放时长自动停止。

### 2.15 首次使用与帮助

- 不做首次启动引导，也不播放一次性提示。
- 首页直接提供“帮助”入口。
- 调音器和节拍器页面提供“帮助”按钮。
- 打开帮助时暂停调音监听；返回后恢复。
- 节拍器播放时打开帮助，节拍器继续播放。
- 节拍器播放时打开帮助，节拍器继续播放。
- 帮助按任务组织，包含：
  - 如何调一根弦。
  - 如何用 VoiceOver 调音。
  - 如何用节拍器。
  - 常见问题。
  - 联系反馈。

### 2.16 设置页

设置按以下分组：

1. 调音：标准音高、准音容差、音名读法、更新播报方式。
2. 声音：参考音音色、提示音音量、语音语速。
3. 节拍器：音色、重音、预备拍、触觉。
4. 无障碍：VoiceOver 帮助、转子说明、盲文显示器提示。
5. 其他：语言、隐私说明、恢复默认设置。

### 2.17 无障碍

- 全流程可用 VoiceOver 完成。
- 主要入口使用标准列表、按钮和可调节控件。
- 自定义转子用于快速切换乐器、弦位和节拍器参数。
- 自定义手势只能作为快捷方式，不能成为唯一入口。
- 兼容 Voice Control、Switch Control、盲文显示器和屏幕 curtain。
- 视觉界面采用高对比、大字、文字和形状提示，不依赖颜色。
- 显示当前模式、目标音、偏差方向、音分数字和主要按钮。

### 2.18 错误与中断

- 麦克风权限被拒绝：语音解释原因，提供打开系统设置的入口；参考音和节拍器仍可使用。
- 没有检测到稳定音高：不反复报错，只在用户查询时提示。
- 电话、Siri 或其他音频中断：暂停当前音频，恢复后明确提示状态。
- 音频输出切换：重新配置音频路由并提示。
- 进入后台：调音器停止聆听；节拍器按设置继续播放。

### 2.19 命名

- 发布名称暂不确定，先使用内部代号。
- 正式名称需要做 App Store 重名和商标检查。

### 2.20 首版验收标准

**调音**

- 安静环境下，稳定单音通常达到 ±3 音分。
- 低音区明确提示结果可能不稳定。
- 拨弦后约 1.5 秒内给出结果。
- 同一个持续音最多自动更新 3 次。

**节拍器**

- 长时间播放无明显漂移。
- 开始、停止、修改 BPM 和测速均可通过 VoiceOver 完成。
- 离开页面和锁屏后继续播放，首页和节拍器页面均能明确显示状态。

**无障碍**

- 核心 VoiceOver 任务全部可完成。
- 调音和节拍器均可在不依赖视觉的情况下完成主要操作。

### 2.21 盲测任务

首轮盲测使用 5 个任务：

1. 打开应用并进入快速调音。
2. 调一根弦并听懂结果。
3. 切换到钢琴并识别一个音。
4. 启动节拍器、修改 BPM、停止。
5. 打开帮助并返回。
