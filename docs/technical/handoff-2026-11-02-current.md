## 1. 项目与用户目标

项目路径：`D:\调音节拍器`

这是一个面向盲人和低视力用户的 iOS SwiftUI 调音节拍器。

用户当前最关心的：

- 节拍器界面简洁，主操作在底部，单手好按。
- 拍号可以点选，也可以在旁白下上下清扫直接调。
- 自定义速度点一下就能弹键盘，右下角“确定”生效。
- 旁白朗读简短准确，不要重复废话。
- SideStore 能无线刷新和更新，不必每次插线。

## 3. 版本与发布流程

- 版本号在 `project.yml`：
  - `CFBundleShortVersionString` / `MARKETING_VERSION`
  - `CFBundleVersion` / `CURRENT_PROJECT_VERSION`
- 构建标记在 `App/Sources/HomeView.swift` 的 `accessibilityIdentifier`，
  必须与 `.github/workflows/ios.yml` 里两处 `grep` 保持一致。
- 当前标记：`METRONOME_INTERACTION_2026_11_02`，版本 0.6.3，构建号 9。
- **从 0.6.3 起，每发一版都要换新的版本号和新的构建标记**，不要复用。
- 发布命令：

```bash
git push origin fix/tuner-lifecycle
git tag -a vX.Y.Z -m "TuneMetronome X.Y.Z"
git push origin vX.Y.Z
```

- 本机 `git push` 偶发 443 超时，可加：

```bash
git -c http.version=HTTP/1.1 -c http.lowSpeedLimit=1000 -c http.lowSpeedTime=30 push
```

## 4. 已完成的节拍器功能

### 主界面（方案 A）

```text
120
BPM
● 已停止

拍号                  4/4  ⇅

[ 测速 ]      [ 输入速度 ]

──────────────────────────
[ − ]      [ 开始 ]      [ + ]
```

- 顶部大号 BPM，下方只写 `BPM`，不写“每分钟拍数”。
- 拍号一行：点击弹出选择页；旁白聚焦后可上下清扫直接调整。
- 底部固定播放/加减控制区，已上移，避免过于贴近 Home Indicator。
- 右上角齿轮进入“节拍器设置”。
- 主界面没有帮助入口，也没有预备拍。

### 拍号交互

- 旁白标签直接是 `4/4 拍`，不再先读“拍号”。
- 上下清扫切换后只播报新值，例如 `6/8`。
- 旁白关闭时点击进入独立的“选择拍号”页，点选即生效并关闭。

### 输入速度

- 点“输入速度”立即展开输入框并弹出数字键盘。
- 键盘工具条右下角是 **“确定”**，点击校验并应用。
- 成功：收起输入区、关闭键盘、播报 `速度已设为 N BPM`。
- 失败：保留键盘，显示中文错误并播报。

### 节拍器设置（摘要式）

```text
节拍器设置
├─ 节拍
│  ├─ 拍号          4/4  ›
│  ├─ 重音     第一拍重音  ›
│  └─ 细分拍          无  ›
├─ 声音
│  ├─ 音色      清脆点击  ›
│  └─ 播放时触觉打拍   [开关]
├─ 测速
│  └─ 显示还差几拍提示 [开关]
└─ 帮助
```

- 每行右侧显示当前值，点进去才是二级列表。
- 不再把所有选项一次铺开。

### 测速

- 前 4 拍给出第一个速度。
- 之后每 4 拍更新一次显示值。
- 速度取最近 8 个拍点间隔的平均值。
- 显示值变化时旁白同步播报，例如 `速度 120 BPM`。
- 3 秒没有新拍点重置；已有结果时不会被清空。
- 结果需手动点“应用到节拍器”，不会自动覆盖。
- “显示还差几拍提示”开关在设置页，默认开启。

### 已删除

- 预备拍：模型、音频调度、界面、测试、旧偏好键全部移除。
  启动时会清理遗留键 `metronome.countIn`。
- 首页“快速开始”分组：与调音器、节拍器重复，已删除。
- 测速的“每拍跟手”模式与平滑系数逻辑：已删除。
